# fb-spielplan

Öffentlicher Spielplan des **SV Chemie Dohna** — wird automatisch aktualisiert.

- **Zur Seite:** https://ghjoe23.github.io/fb-spielplan/
- `spieldaten.json` — aktuelle Spieldaten (maschinenlesbar, Grundlage der Seite)
- `logos/` — Vereinswappen der Spielpartner (Hosting/Backup für Grafiken)
- `logos-test.html` — Link-Test aller gehosteten Wappen

Datenquelle: fussball.de (Vereinsspielplan des SV Chemie Dohna).
